### 🚀 Featured Projects

#### 🏥 [Med-ERP-Microservices](https://github.com/deepbijwe/Med-ERP-Microservices-Project)
End-to-end B2B medical ERP built as three Java/Spring Boot microservices (order, user, product) with MongoDB Atlas. Full DevSecOps pipeline: SonarQube analysis, OWASP Dependency Check, Trivy scans, ECR push, and Kubernetes deployment on EKS behind NGINX Ingress. Frontend hosted on S3 + CloudFront, infra provisioned via a dedicated Terraform pipeline.

#### ✈️ Flight Reservation Platform (three-tier, Terraform + EKS)
Full three-tier deployment: Terraform-provisioned infra (S3 + EKS + RDS), Spring Boot backend deployed via Jenkins to EKS, and a React frontend synced to S3 static hosting through a separate pipeline. Verified end-to-end with live data persistence in RDS.

#### 🔧 [Jenkins CI/CD Pipelines](https://github.com/deepbijwe/Jenkins-Projects)
A collection of Jenkins pipelines covering Maven builds, SonarQube quality gates, Docker-based build agents, image vulnerability scanning with Trivy, and deployments to EKS — including a Node.js → Docker Hub → EKS pipeline with GitHub webhook automation.

#### ☁️ [AWS Projects](https://github.com/deepbijwe/AWS-projects)
Hands-on AWS practicals documented with ASCII architecture diagrams: EC2 provisioning with Terraform, multi-environment workspaces with S3 remote backend, modular EKS clusters, Kubernetes Ingress path-based routing, EBS CSI StatefulSets, and a 3-tier Dockerized app (React + Spring Boot + MariaDB).
